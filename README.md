# c_and_p_test マンガ喫茶 料金計算（CLI）
入店日時・退店日時・コース種別を入力すると、税抜/税込の金額を計算します。

延長は10分単位で切り上げ課金、深夜（22:00〜翌05:00）にかかる延長は15%割増です。

## 要件
実装言語：PHP（DateTimeImmutable）

コースは入店時に確定（通常/3h/5h/8h）

コース時間超過分のみ延長課金（10分単位、1秒でも超過で切り上げ）

深夜割増は延長分のみ対象

深夜帯：22:00:00 〜 翌05:00:00

その10分スロットが1分でも深夜に重なれば、そのスロットは深夜単価（115円/10分）

税：10%・切り捨て（税込＝floor(税抜×1.1)）

タイムゾーン：Asia/Tokyo

## 料金表（税抜）

| コース          | 時間      | 料金         |
| ------------- | --------- | ----------- |
| 通常           | 1時間     | 500円        |
| 3時間パック     | 3時間     | 800円        |
| 5時間パック     | 5時間     | 1,500円      |
| 8時間パック     | 8時間     | 1,900円      |
| 延長（通常）    | 10分ごと   | 100円       |
| 延長（深夜）    | 10分ごと   | 115円（+15%）|
コース	     時間       料金
通常	   1時間	  500円
3時間パック	3時間      800円
5時間パック	5時間	 1,500円
8時間パック	8時間	 1,900円
延長（通常）	10分ごと	100円
延長（深夜）	10分ごと	115円（+15%）

<!-- 深夜割り増しについて -->

ちょうど 22:00:00 に退店 → その直前のスロットは深夜対象外

ちょうど 05:00:00 から延長開始 → その直後のスロットは深夜対象外

## 使い方
### 前提

PHP 8.1+ を推奨

ターミナルから実行

### 実行

php index.php

### 入力例（対話）
入店日時を入力してください
（例：2025-10-30 10:32:36）：
2025-10-30 21:00:00

退店日時を入力してください
（例：2025-10-30 15:41:26）：
2025-10-30 22:10:00

コースを {a:通常、b:3時間パック、c:5時間パック、d:8時間パック} から選択して入力してください

例(3時間パックの場合：b)：
a

コース「通常」が選択されました

### 出力例：
入店：2025-10-30 21:00:00

退店：2025-10-30 22:10:00

税抜価格：615円

税込価格：676円

説明：

通常（1h）= 500円
延長10分が22:00〜22:10に重なる → 深夜単価 115円
小計（税抜）= 500 + 115 = 615円
税込 = floor(615×1.1) = 676円

もう少し例：

<!-- 延長なし（3時間パック） -->
入店 10:00:00 → 退店 13:00:00、コース：3時間
税抜：800円 / 税込：880円

<!-- 1秒超過でも10分課金（通常・昼間） -->
入店 10:00:00 → 退店 11:00:01、コース：通常
コース料金（通常）：500円
延長：10分×100円
税抜：600円 / 税込：660円

<!-- 深夜延長が30分（通常） -->
入店 22:45:00 → 退店 翌日 00:15:00、コース：通常
パック終了：23:45:00
延長：30分 → 3ブロック×115円 = 345円
税抜：500 + 345 = 845円 / 税込：floor(845×1.1)= 929円

## 実装ファイル

index.php … CLIインターフェース（入出力・全体制御）

functions.php … ロジック（日時パース、合計分の算出、延長料金、深夜重なり判定 ほか）

courses.php … コース定義（名称・時間・税抜料金）

## 設計メモ

延長の切り上げ：延長秒数を600秒（10分）で割って**ceil**。

深夜判定：延長を10分スロットに分割し、各スロットが1分でも深夜区間（22:00–24:00／翌0:00–5:00）と重なれば深夜単価を適用。

境界の扱い：判定は半開区間（[start, end)）で実装。22:00ちょうどや05:00ちょうどは深夜に含めない。

税込丸め：切り捨て（floor(税抜×1.1)）。
